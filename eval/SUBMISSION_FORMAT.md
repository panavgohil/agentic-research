# Submission Format

## Overview

Each configuration produces one predictions file at `predictions/<config>.jsonl`.

The following config names are required:

| Config Name       | Description                                      |
|-------------------|--------------------------------------------------|
| `full_agent`      | Full agentic pipeline (planner + retriever + reflector + synthesizer + citation verifier) |
| `baseline`        | Single-shot: one retrieval call + one LLM call, no agent loop |
| `no_planner`      | Agent without the planner; retrieves directly on the raw question |
| `no_reflector`    | Agent without the reflector; never loops back for more evidence |
| `no_citation_verifier` | Agent without citation verification post-processing |
| `no_hybrid`       | Agent using dense-only retrieval (no BM25/sparse component) |

---

## JSONL Format

Each line in `predictions/<config>.jsonl` is a JSON object:

```json
{
  "id": "q01",
  "question": "What is the main motivation behind the KG-Agent framework ...",
  "answer": "The KG-Agent framework was motivated by ...",
  "citations": ["2402.11163v1"],
  "trace": {
    "subquestions": ["What problem does KG-Agent solve?", "..."],
    "retrieval_rounds": 1,
    "tool_calls": 4,
    "reflection_decision": "enough_evidence",
    "latency_seconds": 12.3
  }
}
```

### Field Specifications

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | ✅ | Question ID from `eval/questions.jsonl` |
| `question` | string | ✅ | The question text (copy from questions.jsonl) |
| `answer` | string | ✅ | The synthesized answer text |
| `citations` | list[string] | ✅ | arXiv IDs cited inline (e.g. `"2402.11163v1"`). Must match papers in the corpus. |
| `trace.subquestions` | list[string] | ✅ for `full_agent` | Sub-questions generated by the planner |
| `trace.retrieval_rounds` | int | ✅ | Number of retrieval loops (1 for baseline/no_reflector) |
| `trace.tool_calls` | int | ✅ | Total number of LLM + retrieval calls made |
| `trace.reflection_decision` | string | ✅ | One of: `"enough_evidence"`, `"searched_again"`, `"n/a"` |
| `trace.latency_seconds` | float | ✅ | Wall-clock time for this question |

## Grading

We grade each `predictions/<config>.jsonl` on four axes:

### 1. Answer Accuracy (LLM-as-judge, 0–1)
The reference answer is compared to your answer using GPT-4o-mini as judge.  
Prompt: *"Given the question and a reference answer, score the candidate answer 0–1 for factual accuracy."*

### 2. Faithfulness (LLM-as-judge, 0–1)
Each claim in your answer is checked against your cited passages.  
Faithfulness = fraction of claims that can be grounded in at least one cited chunk.

### 3. Citation Precision (exact set overlap)
```
precision = |predicted_citations ∩ must_cite| / |predicted_citations|
```

### 4. Citation Recall (exact set overlap)
```
recall = |predicted_citations ∩ must_cite| / |must_cite|
```

> **Tolerance**: Your self-reported scores (in your report) must be within ±0.05 of our re-graded scores to pass.

## Submission Checklist

- [ ] `eval/questions.jsonl` — present and unmodified
- [ ] `predictions/full_agent.jsonl` — 30 entries, one per question
- [ ] `predictions/baseline.jsonl` — 30 entries
- [ ] `predictions/no_planner.jsonl` — 30 entries
- [ ] `predictions/no_reflector.jsonl` — 30 entries
- [ ] `predictions/no_citation_verifier.jsonl` — 30 entries
- [ ] `predictions/no_hybrid.jsonl` — 30 entries (or note if hybrid not implemented)
- [ ] Technical report (PDF, 4–6 pages)
- [ ] `README.md` with single-command reproduction instructions

---

## Notes

- `citations` should be arXiv IDs as they appear in the corpus (e.g. `"2402.11163v1"`), **without** the `.json` extension.
- If a config is not applicable (e.g. `no_hybrid` if you never implemented hybrid retrieval), include all 30 entries with `"answer": ""` and note this in the report.
- Latency is measured from question input to final answer output, including all LLM and retrieval calls.
